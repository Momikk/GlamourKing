# 幻化之王 GlamourKing

面向《最终幻想 XIV》幻化柜的 Dalamud 插件。

**当前版本为早期测试版（0.1.0.2）**，用于确认幻化柜检测与插件窗口能否正常工作。目前尚未提供物品检索、收藏管理或幻化配装功能。

## 当前功能

打开幻化柜时自动显示测试窗口，关闭幻化柜时自动收起。窗口显示幻化柜的开关状态、本次插件加载期间的打开次数，以及最近一次打开时间。

支持通过 `/glamking` 手动打开或关闭窗口，也可以从 Dalamud 插件管理器打开主界面。

## 安装方法

1. 在游戏聊天栏输入 `/xlsettings`，进入 **插件 → 第三方插件**。
2. 添加以下仓库链接，勾选启用并保存设置：

   ```text
   https://raw.githubusercontent.com/Momikk/DalamudPlugins/main/pluginmaster.json
   ```

3. 输入 `/xlplugins`，刷新插件列表，搜索 **幻化之王** 或 **GlamourKing**。
4. 安装 **幻化之王 GlamourKing** 并启用。

该链接是 [Momikk 的统一插件仓库](https://github.com/Momikk/DalamudPlugins)。后续更新可直接在 Dalamud 插件管理器中进行。

## 使用方法

安装并启用插件后，前往旅馆等有幻化柜的地点，打开幻化柜即可看到测试窗口。关闭幻化柜后，窗口会自动收起。

如果在幻化柜打开期间手动关闭测试窗口，可以输入 `/glamking` 再次打开，也可以关闭幻化柜后重新打开。插件不会在同一次使用幻化柜期间反复弹出已经手动关闭的窗口。

| 操作 | 作用 |
| --- | --- |
| `/glamking` | 打开或关闭测试窗口 |
| 窗口中的“关闭测试窗口”按钮 | 关闭当前窗口 |
| 插件管理器中的主界面按钮 | 打开测试窗口 |

## 界面预览

当前界面为“幻化之王 · 测试窗口”，包含幻化柜状态、打开次数、最近打开时间和关闭按钮。打开次数在插件重新加载后重新计数；最近打开时间在检测到首次打开幻化柜后显示。

实机截图将在补充后展示于此。

## 适配与使用条件

需要已启用 Dalamud 的游戏环境。当前版本针对 **Dalamud API 15** 构建，使用国服 XIVLauncherCN 的开发程序集完成编译。

国服插件安装器中的显示和图标已确认正常；幻化柜触发窗口的完整实机验收仍待补充。其他区服尚未验证，不保证与国服具有相同表现。游戏或 Dalamud 大版本更新后，请以插件管理器中的兼容状态为准。

普通用户通过插件管理器安装即可，无需自行编译。源码构建与开发加载说明见[开发文档](docs/development.md)。
