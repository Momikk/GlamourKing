# 套装之王 SuitKing

面向《最终幻想 XIV》投影台的 Dalamud 插件，汇总你随身携带、支持套装幻影化的装备。

**当前版本为早期测试版（0.1.0.7）**。打开投影台后，一次查看物品栏和兵装库各分页中的套装装备，无需逐页翻找。

[查看更新记录](CHANGELOG.md)

## 当前功能

识别“套装幻影化”标记对应的装备，汇总物品栏全部四页及兵装库各装备分类。列表显示装备名称、HQ / NQ、所在位置与格数，以及所属套装。同一种装备的多份副本分别显示，不会合并而丢失位置。新增套装保存状态，可按状态筛选。

打开投影台自动显示窗口，关闭投影台后自动收起。投影台打开期间每秒刷新一次，移动、取出或收纳装备后更新列表。支持按装备或套装名称搜索，也可以点击“立即刷新”。新增“隐藏套装中的物品”过滤，可隐藏已登记到装备套装（职业配装）中的装备，并记住你的选择。数据尚未完整加载时会明确提示，不把缺失数据当成没有装备。

范围仅限物品栏和兵装库，不包含身上正在穿戴的装备、雇员、陆行鸟鞍囊或投影台内已经存放的装备。列表表示装备属于游戏支持的套装，不代表已经集齐整套或满足全部收纳条件。


| 套装状态 | 含义 |
| --- | --- |
| 已保存相同套装 | 对应套装中已经保存了这个部件 |
| 可补齐现有套装 | 对应套装已经建立，但其中缺少这个部件 |
| 尚未建立套装 | 投影台中没有建立该装备对应的套装 |
| 待确认 | 套装数据或定义尚未完整加载，暂不分类 |

一件装备属于多个套装时，优先显示可补齐状态；鼠标悬停状态文字可查看各套装的判断。“已保存”不表示整套已经集齐，“可补齐”也不代替游戏对品质和收纳条件的确认。以上状态只检查以套装形式保存的记录，单独保存散件不算建立套装。

## 安装方法

1. 在游戏聊天栏输入 `/xlsettings`，进入 **插件 → 第三方插件**。
2. 添加以下仓库链接，勾选启用并保存设置：

   ```text
   https://raw.githubusercontent.com/Momikk/DalamudPlugins/main/pluginmaster.json
   ```

3. 输入 `/xlplugins`，刷新插件列表，搜索 **套装之王** 或 **SuitKing**。
4. 安装 **套装之王 SuitKing** 并启用。

**从旧版迁移：** 0.1.0.4 起内部标识改为 SuitKing。若仍安装了命名空间为 `glamourking` 的旧插件，请先卸载，再安装新版，避免重复注册命令。已经安装 SuitKing 的用户直接更新即可，统一库链无需更换。

该链接是 [Momikk 的统一插件仓库](https://github.com/Momikk/DalamudPlugins)。后续更新可直接在 Dalamud 插件管理器中进行。

## 使用方法

安装启用后打开投影台，套装之王会自动显示套装装备列表。游戏的“幻影化”装备选择窗口中，右侧带“套装幻影化”按钮的装备，可通过这个汇总列表查找，无需切换物品栏与兵装库分页。

输入装备或套装名称筛选结果。勾选“隐藏套装中的物品”可使用与游戏同名选项对应的过滤；默认未勾选，选择会保存，但不会改变游戏窗口的勾选状态。清空搜索框并取消该勾选即可显示全部。位置列用于找到具体副本；品质列区分 HQ 和 NQ。发现目标装备后，请在游戏原生界面自行操作，插件不会自动收纳或取出物品。

手动关闭插件窗口后，可输入 `/suitking` 或 `/sking` 再次打开，也可以关闭投影台后重开。投影台关闭时，手动打开窗口会提示先打开投影台，不展示上一次会话的旧数据。

| 操作 | 作用 |
| --- | --- |
| `/suitking` 或 `/sking` | 打开或关闭套装之王窗口 |
| “立即刷新”按钮 | 请求重新读取随身装备 |
| 搜索框 | 按装备或套装名称筛选 |
| 套装状态 | 按已保存、可补齐或未建立筛选 |
| 隐藏套装中的物品 | 隐藏已登记到装备套装的装备 |
| 插件管理器中的主界面按钮 | 打开套装之王窗口 |

## 界面预览

界面顶部显示扫描状态、最近刷新时间、刷新按钮、搜索框和套装过滤勾选框，下方以表格展示“装备 / 品质 / 位置 / 套装状态 / 所属套装”。鼠标悬停装备名称可查看物品 ID 与耐久。

## 适配与使用条件

需要已启用 Dalamud 的游戏环境。当前版本针对 **Dalamud API 15** 构建，使用国服 XIVLauncherCN 的开发程序集与本机国服物品数据验证套装映射。

已通过编译、跨分页汇总回归检查及国服套装数据核对。投影台触发窗口、实际物品位置与实时刷新仍需游戏内验收。其他区服尚未验证；游戏或 Dalamud 大版本更新后，请以插件管理器中的兼容状态为准。

普通用户通过插件管理器安装即可，无需自行编译。源码构建、测试及开发加载说明见[开发文档](docs/development.md)。

遇到安装、装备遗漏、位置错误或窗口显示问题，请前往 [GitHub Issues](https://github.com/Momikk/SuitKing/issues) 提交反馈。也欢迎提出功能建议。

请提供插件版本、游戏区服、Dalamud 版本、复现步骤和实际表现。装备筛选问题请尽量附上装备名称、HQ / NQ、所在分页、游戏中“套装幻影化”标记与插件列表的截图；加载问题可附上 `/xllog` 中与 SuitKing 相关的报错。上传前请遮挡角色名等个人信息。
