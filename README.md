# 套装之王 SuitKing

面向《最终幻想 XIV》投影台的 Dalamud 插件，汇总你随身携带、支持套装幻影化的装备。

**当前版本为早期测试版（0.1.0.9）**。打开投影台后，一次查看物品栏和兵装库各分页中的套装装备，无需逐页翻找。

[查看更新记录](CHANGELOG.md)

## 当前功能

识别“套装幻影化”标记对应的装备，汇总物品栏全部四页及兵装库各装备分类。列表只显示装备图标、装备名称、部位、所属套装和套装状态。按主手、副手、头部、身体、手部、腿部、脚部、耳部、颈部、腕部、戒指排序，并按游戏分页的部位组合分组。重复副本分别显示，悬停名称可查看位置与品质。

打开投影台自动显示窗口，关闭投影台后自动收起。投影台打开期间每秒刷新一次，移动、取出或收纳装备后更新列表。主窗口采用游戏原生 UI，使用 28 像素紧凑行距和 24 像素装备图标。“隐藏套装中的物品”位于左侧，分类标签可单击切换，每次打开默认选中“可补齐”。新增“隐藏套装中的物品”过滤，可隐藏已登记到装备套装（职业配装）中的装备，并记住你的选择。数据尚未完整加载时会明确提示，不把缺失数据当成没有装备。原生“幻影化”装备选择列表中的可补齐装备名称会临时标红，与插件当前选中的标签无关；关闭原生界面或禁用插件时恢复原有文字与颜色。

范围仅限物品栏和兵装库，不包含身上正在穿戴的装备、雇员、陆行鸟鞍囊或投影台内已经存放的装备。列表表示装备属于游戏支持的套装，不代表已经集齐整套或满足全部收纳条件。


| 套装状态 | 含义 |
| --- | --- |
| 已保存相同套装 | 对应套装中已经保存了这个部件 |
| 可补齐现有套装 | 对应套装已经建立，但其中缺少这个部件 |
| 尚未建立套装 | 投影台中没有建立该装备对应的套装 |
| 待确认 | 套装数据或定义尚未完整加载，暂不分类 |

一件装备属于多个套装时，优先显示可补齐状态；鼠标悬停状态文字可查看各套装的判断。“已保存”不表示整套已经集齐，“可补齐”也不代替游戏对品质和收纳条件的确认。以上状态只检查以套装形式保存的记录，单独保存散件不算建立套装。

## 安装方法

1. 在游戏聊天栏输入 `/xlsettings`，进入 **插件 → 第三方插件**。
2. 添加以下仓库链接，勾选启用并保存设置：

   ```text
   https://raw.githubusercontent.com/Momikk/DalamudPlugins/main/pluginmaster.json
   ```

3. 输入 `/xlplugins`，刷新插件列表，搜索 **套装之王** 或 **SuitKing**。
4. 安装 **套装之王 SuitKing** 并启用。

**从旧版迁移：** 0.1.0.4 起内部标识改为 SuitKing。若仍安装了命名空间为 `glamourking` 的旧插件，请先卸载，再安装新版，避免重复注册命令。已经安装 SuitKing 的用户直接更新即可，统一库链无需更换。

该链接是 [Momikk 的统一插件仓库](https://github.com/Momikk/DalamudPlugins)。后续更新可直接在 Dalamud 插件管理器中进行。

## 使用方法

安装启用后打开投影台，套装之王默认显示“可补齐”分类。直接点击顶部“全部 / 已保存 / 可补齐 / 未建立”标签切换类别，无需下拉菜单。

勾选“隐藏套装中的物品”可隐藏已登记到装备套装的装备；选择会保存，不改变游戏窗口自身的勾选状态。插件中的名称颜色和游戏列表中的名称颜色相互独立：原生列表只将可补齐装备标红，帮助你定位可以补入已有套装的部件。

发现目标装备后，请在游戏原生界面自行操作。收纳、取出或移动物品后，列表和高亮随自动读取更新，插件不会自动收纳或取出装备。

手动关闭插件窗口后，可输入 `/suitking` 或 `/sking` 再次打开，也可以关闭投影台后重开。投影台关闭时，手动打开窗口会提示先打开投影台，不展示上一次会话的旧数据。

| 操作 | 作用 |
| --- | --- |
| `/suitking` 或 `/sking` | 打开或关闭窗口，打开时默认选中可补齐 |
| 顶部分类标签 | 一次点击切换类别 |
| 隐藏套装中的物品 | 隐藏已登记到装备套装的装备 |
| 悬停装备名称 | 查看具体位置与 HQ/NQ |
| 悬停套装状态 | 查看各所属套装的判断 |
| 插件管理器中的主界面按钮 | 打开窗口并选中可补齐 |

## 界面预览

顶部为分类标签和隐藏套装物品勾选框，下方为按部位分组的五列表格：“图标 / 装备名称 / 部位 / 所属套装 / 套装状态”。已移除大段说明、扫描时间、手动刷新、搜索框和分类下拉框。

主窗口现使用原生皮肤、紧凑行距和左侧过滤开关，原生装备选择列表将可补齐名称标红；实机截图待补充。

## 适配与使用条件

需要已启用 Dalamud 的游戏环境。当前版本针对 **Dalamud API 15** 构建，使用国服 XIVLauncherCN 的开发程序集与本机国服物品数据验证套装映射。

已通过编译、跨分页汇总回归检查及国服套装数据核对。原生 UI 的显示、滚动、主题与缩放、关闭和卸载表现仍需游戏内验收。其他区服尚未验证；游戏或 Dalamud 大版本更新后，请以插件管理器中的兼容状态为准。

普通用户通过插件管理器安装即可，无需自行编译。源码构建、测试及开发加载说明见[开发文档](docs/development.md)。

## 项目声明

插件读取装备数据并提供汇总，临时调整原生列表的可补齐名称颜色，不修改物品或幻化模板，不自动进行套装幻影化。收纳前请在游戏中确认所需部件、品质和其他条件。功能仍处于早期开发阶段，使用第三方插件可能存在风险，请自行评估。
